# Errgo.Analyzer

Roslyn analyzers that enforce the errors-as-values style of [Errgo](https://www.nuget.org/packages/Errgo/).

## Install

```bash
dotnet add package Errgo.Analyzer
```

The analyzer installs as a build-time tool: it runs in your IDE as you type and highlights violations of the Errgo error-handling conventions directly in the editor.

## Requirements

- Visual Studio 2019 16.7+ or .NET SDK 3.1+ running Roslyn 3.3 or later
